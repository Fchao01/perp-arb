这个筛选器如何判断

每个结果都保留假设，避免把报价优势误认为已实现利润。

01 / OBSERVE

观察同数量深度

默认每 5 秒发起一次探测，按目标买入金额确定数量；延迟后仍按原数量报价。缺深度、断线或调度过晚的观测不能当成成功。

02 / FREEZE

先训练，后冻结

只用第一段数据的中线和方向分位数确定阈值。后续验证不重新拟合，避免用未来数据美化结果。

03 / ROUND TRIP

验证完整往返

先根据当时盘口决策，再用延迟后的报价估算双腿执行；反向退出也有延迟。强制退出、剩余库存与观测中断分别显示。

04 / REVIEW

实盘前还要核验

模型假设双腿完整成交，不预测排队、部分成交、冲击或单腿风险。资金费、指数与合约规格、抵押品换算需要进一步确认。
